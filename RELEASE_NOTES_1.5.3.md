# FreeMyTV LDZ 1.5.3

- Direciona o menu **Atualizações** para as releases do FreeMyTV LDZ.
- Prepara a instalação de futuras atualizações pelo próprio menu, mantendo a assinatura LDZ.
- Compatível com Android TV 9 ou superior.

Esta cópia assinada fica arquivada localmente em `outputs/1.5.3/FreeMyTV-LDZ.apk`. Para baixar a versão atual, consulte [Releases no GitHub](https://github.com/ludezam/FreeMyTV-LDZ/releases).
